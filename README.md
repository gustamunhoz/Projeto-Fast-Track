# Projeto-Fast-Track

 Sobre o projeto FastTrack

O **FastTrack** é um sistema simples de atendimento desenvolvido em Python. A ideia do projeto é simular uma fila de chamados, onde o usuário consegue cadastrar um cliente, definir se o atendimento é normal ou urgente, atender o próximo cliente e visualizar quem ainda está esperando.

Durante o desenvolvimento, foram utilizados alguns conceitos que estou aprendendo no curso de Análise e Desenvolvimento de Sistemas, como **variáveis, funções, condicionais, estruturas de repetição, listas, dicionários e tratamento de erros**. Também utilizei as bibliotecas `datetime` para registrar o horário em que o chamado foi criado e `random` para gerar um número de identificação para cada chamado.

A fila funciona seguindo o conceito **FIFO (First In, First Out)**, ou seja, quem entra primeiro é atendido primeiro. Para isso, utilizei uma lista em Python e o `pop(0)` para retirar o primeiro chamado da fila.

Esse projeto foi importante para mim porque consegui colocar em prática vários conteúdos que estou aprendendo na faculdade. Ainda estou no processo de aprender programação, então o objetivo principal foi entender como cada estrutura funciona e conseguir juntar esses conhecimentos em um programa que realmente funciona.
